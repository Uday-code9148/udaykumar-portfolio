# Profile Picture Instructions

To add your profile picture to the portfolio:

1. **Save your profile picture** in this directory (`assets/images/`) with one of these names:
   - `profile.jpg` (recommended)
   - `profile.png`

2. **Image requirements:**
   - Recommended size: 400x400 pixels or larger
   - Format: JPG or PNG
   - The image will be automatically cropped to a circle and resized

3. **The profile picture will appear in:**
   - Navigation bar (desktop and mobile versions)
   - Home screen profile card

4. **Fallback:** If no image is found, the portfolio will display your initials instead.
